# Project: Sistema De Validación

This project is a simple web application that displays a form for users to enter their name and age.

## Current Status

The application currently consists of an HTML page (`index.html`) that presents the input form and includes basic styling (`src/css/style.css`).

The JavaScript file (`src/js/sistema_interactivo.js`) intended for form validation and interaction is currently empty. Therefore, there is no client-side validation or data processing implemented at this time.

## How to View

1. Clone or download this repository.
2. Open the `index.html` file in your web browser.

You will see the form, but submitting it will not trigger any actions due to the unimplemented JavaScript functionality.

## Future Development

The `src/js/sistema_interactivo.js` file can be developed to add:
- Input validation for the name and age fields.
- Feedback messages to the user based on the validation.
- Potential submission of the data to a backend (not currently part of the project).
